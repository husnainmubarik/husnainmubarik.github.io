# Muhammad Husnain Mubarik - Personal Website

Personal academic website for Muhammad Husnain Mubarik.

**Website:** https://husnainmubarik.github.io/

## About

This website showcases:
- Academic bio and career highlights
- Publications and research papers
- Curriculum vitae

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to view the site locally.
